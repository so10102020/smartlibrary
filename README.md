# 図書館循環システム (Library Circulation System)

Firebaseを使用した図書館の蔵書管理・貸出管理システムです。

## 機能

- 📚 蔵書管理
- 👥 ユーザー管理
- 📖 貸出・返却管理
- 🔍 OPAC（蔵書検索）
- 📊 管理者ダッシュボード
- 📷 バーコードスキャナー機能

## 技術スタック

- Frontend: HTML, CSS, JavaScript
- Backend: Firebase (Firestore, Authentication)
- その他: Firebase Hosting

## セットアップ

1. リポジトリをクローン
2. Firebaseプロジェクトを作成
3. Firebase設定ファイルを更新
4. `firebase deploy`でデプロイ
